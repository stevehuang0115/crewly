# Category rules

A transaction belongs to the first category whose keyword appears in its
description (case-insensitive). A transaction that matches no keyword is
**uncategorized**: it is left for the owner to decide and is excluded from the
totals.

| Category          | Keywords                                  |
|-------------------|-------------------------------------------|
| sales             | Stripe payout, Shopify payout             |
| software          | Adobe, Google Workspace, Zoom             |
| travel            | Uber, Lyft                                |
| office_supplies   | Office Depot                              |
| advertising       | Meta Ads                                  |
| rent              | Rent                                      |
