# Publish Checklist

**Trigger**: before_publish
**Applies to**: *
**Version**: 1.0.0

## Overview

This is the final gate before any content goes live. Run through every item
after content review is complete and all revisions are applied.

## Steps

1. **SEO Final Check**
   - Title tag set and within 50-60 chars
   - Meta description set and within 150-160 chars
   - URL slug is clean, lowercase, hyphenated (no dates or IDs)
   - Canonical URL set correctly (avoid duplicate content)
   - Schema markup added if applicable (article, FAQ, how-to)

2. **Image Verification**
   - All images load correctly (no broken references)
   - Images compressed (< 200KB for web, < 500KB for hero)
   - Alt text on every image (descriptive, includes keyword where natural)
   - Image dimensions match platform requirements
   - Nano Banana credits included where applicable

3. **Link Audit**
   - All internal links resolve (no 404s)
   - All external links open in new tab (`target="_blank"`)
   - External links point to authoritative, current pages
   - No affiliate links without disclosure
   - CTA links tested and working

4. **Cross-Platform Formatting**
   - Blog post renders correctly in web preview
   - Social posts fit platform character limits (X: 280, LinkedIn: 3000)
   - Email version displays properly in major clients
   - Mobile layout verified (responsive, no horizontal scroll)

5. **Compliance & Legal**
   - No copyrighted images without license
   - Proper attribution for quotes and data
   - Disclosure added for sponsored content
   - GDPR/privacy considerations for any personal data references

## Checklist

- [ ] SEO metadata complete (title, meta, slug, canonical)
- [ ] All images load, compressed, and have alt text
- [ ] All internal links resolve (no 404s)
- [ ] All external links work and open in new tab
- [ ] CTA links tested
- [ ] Renders correctly on desktop and mobile
- [ ] Social posts within platform character limits
- [ ] No copyright violations
- [ ] Proper attributions included
- [ ] Final proofread complete
